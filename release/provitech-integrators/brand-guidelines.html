08 / MOTION & INTERACTION

Motion & Interaction Foundation

Engineered, purposeful movement that reinforces technical authority and industrial security precision. Free of decoration or gimmicks.

LEVEL 1

Micro-Interactions

Immediate, tactile interface feedback powered entirely by native CSS transitions. Zero runtime script overhead.

  • Scope: Buttons, links, arrows, form inputs, nav indicators
  • Engine: Pure CSS transitions (var(--transition-fast))
  • Duration: 150ms–250ms (Micro to Fast)
  • Trigger: User input (:hover, :focus-visible, :active)
LEVEL 2

Entrance & Reveal

Coordinated, viewport-aware scroll entrance sequences powered by GSAP Core and ScrollTrigger.

  • Scope: Headings, intro copy, card grids, hardware panels
  • Engine: GSAP Core + ScrollTrigger (once: true)
  • Duration: 350ms–500ms (Standard)
  • Trigger: Natural viewport entry (never scrubbed by default)
LEVEL 3

Storytelling & Showcase

Orchestrated multi-layer narrative sequences reserved strictly for high-impact brand moments.

  • Scope: Hero opening sequence, interactive workflow walkthroughs
  • Engine: GSAP Timelines with controlled sequencing
  • Duration: 800ms–1200ms (Storytelling)
  • Trigger: Phase-gated approval (strictly locked in Phase 4.7)

Duration Scale

--motion-duration-micro 180ms Micro feedback, icons, arrows
--motion-duration-fast 250ms Button hovers, drawer toggle
--motion-duration-standard 400ms Standard scroll reveals, cards
--motion-duration-slow 650ms Complex panels, section transitions
--motion-duration-story 950ms Hero sequence branding moments

Easing Vocabulary

power2.out Standard Natural deceleration for general UI
power3.out Entrance Decisive stop for arriving elements
power2.in Exit Prompt departure without lingering
power2.inOut Emphasis Symmetrical focus for toggle cues
bounce / elastic PROHIBITED No bouncy cartoon motion permitted

Motion Rules & Engineering Guardrails

  • Movement Ceilings: Entrance translations are strictly constrained to 12px–40px (--motion-distance-sm to --motion-distance-lg). Never use 100px+ slides.
  • Interactive Scale Limits: Scale is restrained to 0.98 (active compression) and 1.02 (hover lift). Maximum scale ceiling is 1.03.
  • Stagger Cadence: Stagger delays range between 0.05s and 0.12s, ensuring content is revealed quickly without making the user wait.
  • Performance Priority: Strictly animate only GPU-composited properties: transform and opacity. Never animate width, height, top, left, or margins.
  • No Scrub by Default: Reveals trigger once and play forward to completion (play none none none). Scrub is reserved strictly for continuous spatial timelines.

Accessibility & Failure Safety Standards

  • Mandatory Reduced Motion: When prefers-reduced-motion: reduce is active, all entrance animations, transforms, and scrub effects are skipped instantly. Content remains immediate and fully visible.
  • No-JS / No-GSAP Safety: Never style elements with initial CSS opacity: 0. All markup remains 100% visible in the DOM by default. If GSAP fails or is blocked by network policies, the website operates seamlessly.
  • No Scroll-Jacking: No hijacking native browser scroll dynamics, no pinning without explicit phase approval, and no continuous reverse replaying.
  • Responsive Differentiation: Mobile devices (≤768px) receive shorter movement distances (8–16px) and reduced complexity via gsap.matchMedia().

  • Active Indicator: Persistent scaleX(1) underline on active page/route link.

  • Toggle Button: Smooth rotational fade between hamburger lines and close X.
  • Drawer Entrance: Container fades and slides (280ms, power3.out) with staggered nav links (0.045s stagger) followed by mobile CTA.

Hero Motion & Interactive Elements Specification

Cinematic opening sequence, two-stage headline reveal, pointer-based CCTV depth parallax, and discrete scroll depth separation for the PROVITECH primary hero interface.

  • Two-Stage Headline: Line 1 ("See more.") reveals at 0.46s (0.55s duration); Line 2 ("Worry less.") follows at 0.64s with Electric Blue emphasis.
  • Paragraph & CTAs: Supporting copy enters at 0.80s, followed by Primary CTA at 0.92s and Secondary CTA at 1.02s.

2. Interactive Dynamics & Depth

  • Desktop Pointer Parallax: CCTV image shifts opposite cursor position via performant gsap.quickTo, strictly capped at ±6px displacement. Fine pointer only ((pointer: fine)).
  • Scroll Exit Depth: Lightweight ScrollTrigger gently lifts content 24px (y: -24) as user scrolls away; zero section pinning, zero scroll-jacking.
  • Scroll Cue Loop: Subtle 3px vertical arrow bob loop (2.0s duration, gentle ease). Automatically paused via ScrollTrigger when scrolled past Hero to conserve CPU cycles.
  • Button Micro-Feedback: 2px lift, 4px arrow right glide, tactile 0.98 active press scale.

3. Responsive Adaptation

  • Mobile Viewports (≤768px): Simplified single-axis translations (8px–12px), faster timings (0.38s–0.42s), disabled image scale, zero pointer parallax.
  • Tablet Viewports (769px–900px): Moderate 16px entrance movement; pointer parallax disabled on touch-first displays.
  • Clean Breakpoints: Controlled via gsap.matchMedia(); all inline styles purged on resize to prevent broken layouts.

4. Failure Safety & Reduced Motion

  • Mandatory Reduced Motion: When prefers-reduced-motion: reduce is active, all entrance transforms, CCTV scaling, pointer parallax, and scroll cues are instantly bypassed. Content renders immediately in final resting state.
  • No-GSAP / No-JS Safety: Hero markup starts 100% visible in the DOM. All CTAs and links remain fully operational without JavaScript.
  • Scroll Restoration Safety: If page refreshes mid-page or bottom (scrollY > 150px), entrance sequence jumps directly to completion to prevent off-screen recalculation jank.
